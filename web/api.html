被拒绝的常见原因
返回中的字段含义处理方式
unmapped字段名或 LOINC 编码不在本系统的变量字典内确认指标是否需要纳入；如需纳入，在变量字典中补充映射
unit_rejected单位与常用单位不符（例：肌酐用 umol/L 而系统按 mg/dL 解读）让对方按常用单位发送，或在适配器中配置换算
ok: false报文为空、缺少患者编号，或未解析出任何可识别观测核对 PID-3 患者编号与 OBX-3 编码
ok: false缺少患者编号（patient_id / pid / subject / mrn）推送体必须带患者唯一编号
本系统输出的是风险提示，不构成医疗诊断，临床决策请遵医嘱。
